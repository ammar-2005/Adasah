## 🚀 About The Project
**Adasah** is a specialized photography blog designed to share professional photography secrets, practical tips, and step-by-step tutorials. Built with a modern tech stack, the platform features a sleek Dark Mode interface with warm orange accents, offering an immersive reading experience for photography enthusiasts.

### ✨ Key Features
- **🗂️ Article Categorization:** Browse articles by specific topics (Lighting, Portrait, Landscapes, Techniques, Equipment).
- **🔍 Smart Search:** Powerful substring search that looks through article titles, excerpts, and full content.
- **📱 Fully Responsive Design:** Seamlessly adapts to all screen sizes (Mobile, Tablet, Desktop).
- **🎨 Modern Dark Theme:** A sleek, eye-friendly dark UI with elegant orange gradients and FontAwesome icons.
- **🔄 Advanced Routing:** Smooth page navigation and dynamic nested routes using `react-router-dom`.
- **📄 Local Data Management:** Uses a structured local JSON file to store and manage blog content efficiently.

## 🛠️ Built With
*   **[React.js](https://react.dev/):** The core UI library.
*   **[Tailwind CSS](https://tailwindcss.com/):** Utility-first CSS framework for rapid styling.
*   **[React Router DOM](https://reactrouter.com/):** Declarative routing for React applications.
*   **[FontAwesome](https://fontawesome.com/):** Icon library for beautiful UI elements.
*   **[Vite](https://vitejs.dev/):** Next-generation frontend tooling.
